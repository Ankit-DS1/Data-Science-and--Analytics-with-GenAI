# Sheryians Coding School

![Sheryians Coding School Logo](https://dfdx9u0psdezh.cloudfront.net/logos/c6ea73c88f48c1236e7f94e8.webp)

This repository contains learning materials and solutions from the Sheryians Coding School course. The course covers Python fundamentals, data analysis with NumPy and Pandas, and general coding practice.

## Course Highlights

- Python basics and operators
- Control flow, loops, and functions
- Data structures: lists, tuples, sets, dictionaries
- Exception handling and file I/O
- Object-oriented programming concepts
- NumPy and Pandas for data analysis

## Repository Structure

- `Python Powerhouse/` - Python fundamentals and programming practice
- `NumPy/` - NumPy exercises and solutions
- `Pandas/` - Pandas exercises and solutions
